## Cara Menjalankan

Kompilasi lalu jalankan dengan JDK:

```bash
javac NamaFile.java
java NamaFile
```

Khusus Client-Srver (RMI), jalankan `Server` terlebih dahulu, lalu `Client` — sesuaikan IP server di kedua file.
